# Exports using the supplied documents

Automatic spreadsheet exports fill only the supplied worksheets. They produce one workbook for the selected scope, without a replacement Transactions worksheet, product-specific files or ZIP delivery.

Choose **Export official document**, leave **All matching records (automatic)** selected, select the college / operating unit and other applicable filters, and choose **All classifications** when both classes are required. Select **Preview document**, review the applicable worksheets, then download the complete document.

Products and requests fill consecutive rows. Different recipients, dates, statuses and sessions do not trigger repeated forms. Each selected record retains its own row, including distinct requests involving the same asset. Original copies required by the template, including both ICS copies, remain together.

Description cells contain the saved description only. Blank descriptions stay blank. Actual recorded remarks remain in dedicated fields, while conflicting shared receiver/date fields remain unfilled. Unused item-entry rows are removed; populated rows can wrap and grow to keep actual content readable. Footer fields, formulas, merges, drawing anchors and print bounds move with the compact table. Original-reference previews and downloads retain their blank rows.

Documented Information is a manual document-copy request under Requests & Returns. It is not a Category History export and does not receive asset history in its Purpose field. Use the chronological history table and each event's linked supporting form instead.

The server verifies authorization and source/reference versions before output. Preview navigation never slices the complete download. No reference files, working copies or their hash manifest should be removed when packaging the application.

The visual preview is a review aid, not an exact native print proof. Verify Office pagination and formal signatures before printed submission. See [API and access](reference-form-export.md), [classification coverage](all-classifications.md) and [college-wide exports](college-batch-export.md).
