# All classifications

Choose **All classifications** to include PPE and semi-expendable records in the authorized scope. College and product-category filters limit which records are included; document purpose determines which supplied worksheets are used.

| Purpose | Supplied forms |
|---|---|
| Accountability / item acknowledgment | PAR and ICS |
| Physical count | RPCPPE and RPCSP |
| Transfer | PTR and ITR |
| Return | The applicable sheets of the supplied return workbook |

The result is one Excel workbook. Empty classifications do not receive invented data, and the application does not create a separate file or form for each product. Selecting one specific form intentionally limits its classification coverage.

Description cells contain only saved descriptions. Shared fields are filled only when all selected records agree; conflicting values stay blank. Metadata remains available in the application rather than being added to descriptions or remarks.

See [Supplied-document exports](single-workbook-export.md) for preview, compact rows, corrections and template preservation.
